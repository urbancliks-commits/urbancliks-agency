## Project Overview

Urbancliks is a Dubai-based social media agency specialising in social media management, strategy, and content creation. This repository contains:

- **Marketing website** — public-facing site showcasing services, portfolio, team, and contact information
- **Internal tooling** — agency-side tools for content planning, scheduling, and client reporting

## Recommended Stack (not yet implemented)

- **Next.js 14+ (App Router)** with TypeScript — marketing pages use static generation for SEO; internal tools use protected authenticated routes
- **Tailwind CSS** — utility-first styling
- **Prisma + PostgreSQL** — data layer for internal tooling
- **NextAuth.js** — authentication for internal routes
